Well AI

Чатбот, который умеет общаться, писать код, объяснять решения и генерировать картинки. По умолчанию отвечает локальной разговорной моделью qwen2.5:3b через Ollama — без API-ключа и без интернета. Ответ появляется потоково, как в настоящем ИИ-чате. История хранится только у тебя.

Живой диалог

Собственный стиль Well AI: тёмно-синий фон, мятный и фиолетовый акценты, золотая деталь. Ответ пишется на глазах: аватары, подписи «вы / well ai», индикатор набора и блоки кода с кнопкой «Копировать». Модель можно переключить прямо в шапке.

Локально и приватно

Чаты и ключ лежат в %APPDATA%\Well AI. Для общения ключ не нужен — модель работает на этом ПК.

Как начать

Скачай и запусти установщикПрограмма появится в меню «Пуск» и на рабочем столе.
Ollama поднимется самаЕсли сервис или модель qwen2.5:3b не установлены, Well AI запустит Ollama и скачает модель. Ключ для чата не нужен.

Вопросы

Нужен ли API-ключ?

Для чата — нет: по умолчанию используется локальная разговорная модель qwen2.5:3b через Ollama на http://127.0.0.1:11434/v1. Для генерации картинок нужен ключ OpenAI (поле «API-ключ» и «API Base для картинок»).

Где хранится ключ?

В файле %APPDATA%\Well AI\config.json. Не публикуй этот файл. Удаление настроек предлагается при uninstall.

Почему картинка не генерируется?

Проверь, что у ключа есть доступ к выбранной модели картинок. Для OpenAI попробуй gpt-image-1 или dall-e-3 и разрешённый размер.

Как обновить?

Скачай новый установщик и запусти его — он перезапишет файлы программы, сохранив настройки и историю.
