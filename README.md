# Well AI

Локальный Windows-чатбот, который умеет отвечать на вопросы, писать код и генерировать картинки через OpenAI-совместимый API.

## Что умеет

- Диалог с историей сообщений (история хранится только на твоём ПК).
- Генерация кода с пояснениями и примерами запуска.
- Генерация картинок с сохранением в `Pictures\Well AI`.
- Настройка модели чата, модели картинок, размера, температуры и системного промпта.
- Работает без Python/Node — только встроенный Windows PowerShell 5.1.
- API-ключ хранится в `%APPDATA%\Well AI\config.json`, не отсылается никуда, кроме выбранного API.

## Установка

1. Скачай `WellAI-Setup.exe` с [сайта](https://abibaokak.github.io/well-ai/) или из [релиза](https://github.com/abibaokak/well-ai/releases/latest).
2. Запусти установщик. Он скопирует программу в `%LOCALAPPDATA%\Well AI` и создаст ярлыки в меню «Пуск» и на рабочем столе.
3. Запусти `Well AI` и открой «Настройки».
4. Вставь API-ключ. По умолчанию используется `https://api.openai.com/v1` и модели `gpt-4o-mini` / `gpt-image-1`.

Для других провайдеров измени `API Base`, `Модель для чата` и `Модель для картинок` в настройках. Если провайдер не поддерживает генерацию картинок — оставь поле пустым или используй OpenAI.

## Управление

- `Enter` — отправить сообщение.
- `Shift+Enter` — новая строка.
- `Картинка` — сгенерировать изображение по тексту из поля ввода.
- `Копировать` — скопировать весь диалог в буфер.
- `Папка картинок` — открыть папку с сохранёнными изображениями.
- Меню «Файл → Очистить диалог» — удалить историю.

## Сборка из исходников

```powershell
powershell -ExecutionPolicy Bypass -File .\installer\build-setup.ps1
```

Результат появится в `dist/`:

- `WellAI-Setup.exe` — установщик;
- `WellAI-portable.zip` — архив с `install.bat`.

## Удаление

Меню «Пуск → Uninstall Well AI». Программа спросит, удалять ли настройки и историю.

## Файлы

- `src/WellAI.ps1` — основная программа.
- `src/wellai.ico` — иконка.
- `installer/install.ps1` — установка.
- `installer/uninstall.ps1` — удаление.
- `installer/config.default.json` — конфиг по умолчанию.
- `installer/build-setup.ps1` — сборка EXE и ZIP.
- `site/index.html` — страница GitHub Pages.

## Безопасность

API-ключ хранится в открытом виде в `%APPDATA%\Well AI\config.json` под твоим пользователем Windows. Не публикуй этот файл и не отправляй его никому.
