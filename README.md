# Well AI

Локальный Windows-чатбот, который умеет отвечать на вопросы, писать код и генерировать картинки. С версии 1.3.0 чат по умолчанию работает на разговорной локальной модели `qwen2.5:3b` через Ollama — без API-ключа и без интернета. Генерация картинок использует OpenAI-совместимый Images API.

Версия 1.4.0:
- собственный визуальный стиль Well AI: тёмно-синий фон `#0a0f1e`, мятный `#3ddcba`, фиолетовый `#7b8dff/#a878ff` и золотой `#ffc46b` — без копирования чужих интерфейсов;
- обновлён и WinForms-интерфейс, и HTML-чат: логотип, активный чат, кнопки, верхняя акцентная линия, поле ввода и статус;
- у сообщений появились подписи «вы» и «well ai», код получил подсветку языка и аккуратную обёртку;
- сохранены потоковый вывод, выбор модели, локальный чат без ключа и генерация картинок.

Версия 1.3.0:
- живой потоковый ответ: текст появляется по мере генерации, как в обычном ИИ-чате;
- модель по умолчанию изменена на `qwen2.5:3b` — нормальные человеческие диалоги на русском, без «рассуждений вслух»;
- выбор модели вынесен в шапку окна и в настройки;
- если модели нет на ПК, приложение само скачивает её через Ollama;
- Ollama автоматически запускается, если сервис не работает;
- обновлён системный промпт: суть сначала, короткие абзацы, код только когда нужен.

Версия 1.2.0:
- красивый интерфейс: аватары, аккуратные карточки сообщений, градиенты, индикатор набора;
- блоки кода с подписью языка и кнопкой «Копировать»;
- стартовый экран с готовыми примерами запросов;
- подсветка активного чата и эффекты наведения в сайдбаре;
- кнопка «+ Новый чат» и список последних диалогов;
- кнопка «Файл» — прикрепление текста/кода из файла к сообщению;
- исправление `???`: запросы теперь отправляются в UTF-8, русские ответы больше не ломаются;
- старые сломанные диалоги больше не переносятся в новые чаты.

## Что умеет

- Диалог с историей сообщений (история хранится только на твоём ПК).
- Генерация кода с пояснениями и примерами запуска.
- Генерация картинок с сохранением в `Pictures\Well AI`.
- Настройка модели чата, модели картинок, размера, температуры и системного промпта.
- Работает без Python/Node — только встроенный Windows PowerShell 5.1.
- API-ключ хранится в `%APPDATA%\Well AI\config.json`, не отсылается никуда, кроме выбранного API.

## Установка

1. Скачай `WellAI-Setup.exe` с [сайта](https://abibaokak.github.io/well-ai/) или из [релиза](https://github.com/abibaokak/well-ai/releases/latest).
2. Запусти установщик. Он скопирует программу в `%LOCALAPPDATA%\Well AI` и создаст ярлыки в меню «Пуск» и на рабочем столе.
3. Запусти `Well AI`. Чат сразу работает на локальной модели: `http://127.0.0.1:11434/v1`, модель `qwen2.5:3b`. Если Ollama или модель не установлены, приложение поднимет сервис и скачает модель само.
4. Чтобы генерировать картинки, открой «Настройки» и вставь API-ключ. Для картинок по умолчанию используется `https://api.openai.com/v1` и модель `gpt-image-1`.

В настройках есть отдельные поля `API Base для чата` и `API Base для картинок`, поэтому локальный чат и облачная генерация изображений не мешают друг другу.

## Управление

- `Enter` — отправить сообщение.
- `Shift+Enter` — новая строка.
- `Картинка` — сгенерировать изображение по тексту из поля ввода.
- `Копировать` — скопировать весь диалог в буфер.
- `Папка картинок` — открыть папку с сохранёнными изображениями.
- Меню «Файл → Очистить диалог» — удалить историю.

## Сборка из исходников

```powershell
powershell -ExecutionPolicy Bypass -File .\installer\build-setup.ps1
```

Результат появится в `dist/`:

- `WellAI-Setup.exe` — установщик;
- `WellAI-portable.zip` — архив с `install.bat`.

## Удаление

Меню «Пуск → Uninstall Well AI». Программа спросит, удалять ли настройки и историю.

## Файлы

- `src/WellAI.ps1` — основная программа.
- `src/wellai.ico` — иконка.
- `installer/install.ps1` — установка.
- `installer/uninstall.ps1` — удаление.
- `installer/config.default.json` — конфиг по умолчанию.
- `installer/build-setup.ps1` — сборка EXE и ZIP.
- `site/index.html` — страница GitHub Pages.

## Безопасность

API-ключ хранится в открытом виде в `%APPDATA%\Well AI\config.json` под твоим пользователем Windows. Не публикуй этот файл и не отправляй его никому.
